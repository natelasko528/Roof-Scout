🚀 Recommended Optimizations

High Priority

  • Remove debug code: Configure Vite to exclude debug_node.mjs in production (-1.2 MB)
  • Optimize filtering: Memoize filteredLeads based on filter changes (-90% filter time)
  • Add quota checks: Use navigator.storage.estimate() before writes

Medium Priority

  • Image compression: Lower default JPEG quality from 0.85 to 0.7 (-30% size)
  • Virtual scrolling: Angular CDK for lead list with 100+ items
  • Marker clustering: For map view with 100+ markers
  • Compress localStorage: Use pako/gzip for data (-60-80% size)

Low Priority

  • Lazy loading: Route-based code splitting (-100-200 KB)
  • Service worker: Cache API responses for offline support
